# FDE Exam Coach — 项目目标与开发原则

## 产品愿景

构建一款 AI 驱动的智能职业认证备考产品，通过自适应刷题、错题诊断、知识点掌握评估和智能复习，提高用户备考效率。

## Phase 1：个人 FDE 考试备考

**截止日期：2026-11-23 上午**

核心目标：帮助项目创建者通过腾讯云 FDE 认证考试。

- 基于 FDE_Learning 的题库与考试能力。
- 参考 wrong-notebook 的 AI 错题分析和复习机制。
- 提供刷题、模拟考试、AI 讲解、知识点掌握追踪及每日复习。
- 重点记录模拟成绩、薄弱知识点和实际学习进展。
- 保证学习记录可备份、恢复及未来迁移。
- 不开发与考试提分无直接关系的功能。

阶段验收：系统稳定可用，完成核心知识点复习与模拟考试训练，为实际考试做好准备。正式考试通过情况作为最终结果验证。

## Phase 2：微信小程序产品化

**启动时间：2026-11-23 考试结束后**

核心目标：把个人备考工具升级为可以公开使用的微信小程序。

- 新增微信小程序客户端。
- 接入微信登录与多用户数据隔离。
- 提供云端学习记录和设备同步。
- 优化移动端刷题体验。
- 支持 AI 智能辅导、错题复习及学习报告。
- 完成题库授权、隐私保护、上线合规及审核准备。
- 先验证 FDE 用户需求，再考虑多考试品类扩展。

## 架构原则

1. thirdparties 中的项目作为只读参考，不直接修改。
2. 将题库、考试、评分、学习记录、复习算法与 UI 解耦。
3. 业务核心尽量做到 Web 与小程序共用。
4. 第一阶段采用单用户模式，但数据结构预留用户隔离能力。
5. 保留数据迁移与备份机制，避免第二阶段重做。
6. 所有重要业务逻辑必须有自动化测试。
7. 考试前的开发优先级始终服从备考效果。
8. 不提前开发第二阶段的用户系统、运营后台或付费功能。
