# FR-014 错题/收藏后台自动预热考点拆解缓存

- 日期：2026-11-04 深夜上线（用户需求原话："错误的题，还有收藏的题目，后台会自动生成考点速览"）
- 目标：错题与收藏的考点拆解在后台自动生成好，用户点开「考点速览」时缓存直出、零等待。

## 设计

### 选择规则（ai/auto.py pending_questions）

- 入选：题目**末次作答错误**，或**已收藏**（收藏题允许从未作答）。
- 排除：当前内容版本已有拆解缓存（`service.breakdown_cached` 命中即跳过；题库改版 → 缓存失效 → 重新生成）。
- 顺序：最近作答的在前；每轮限量 8 道，避免长占。

### 生成节奏（run_cycle）

- 逐题串行调用 `service.breakdown`（自动参与**同题并发去重闸门**：与用户手动点"生成"撞车时自动排队，不双花）。
- 每题间隔 5 秒错峰；单题失败只记日志 `[auto-prewarm] <id> 拆解失败：<原因>`，不中断本轮。
- 每日限额：无（FR-013-CACHE 后用户已要求移除拆解限额，803dadb）。

### 触发（server.py）

- 服务启动 2 秒后先跑一轮（消化存量错题/收藏）。
- 每次 `PUT /api/state` 成功（新的错题/收藏入库）→ `AUTO_EVENT.set()` 立即唤醒。
- 兜底：每 5 分钟自动醒一次。
- 未配置 api_key（如测试环境 data-dir）→ 静默跳过，不影响测试。

## 实现

- `app/ai/auto.py`（新增）：`pending_questions` / `run_cycle`，纯函数可测。
- `app/server.py`：`AUTO_EVENT` + `auto_prewarm_loop` 守护线程 + PUT 唤醒钩子 + main 启动。
- `app/tests/test_auto.py`（新增 6 用例）：选择（末次答错/仅收藏/挽回跳过/题库外 id 忽略/缓存跳过/改版重生成/顺序与限量）、run_cycle（按序生成+落缓存+错峰、单题失败不中断且不落缓存）。

## 验证

- 全量回归：python 全绿（含新 6 用例）、node 66/66。
- 真机：服务重启后日志出现 `[auto-prewarm] FDE-M3-172 拆解完成（cached=False）` 等，`ai-explanations.json` 拆解缓存 10→13 持续增长；与用户同时在线刷题（同题 POST）无冲突。

## 踩坑（两处，当天修复）

1. `log=print` 在后台线程 + launchd 文件重定向下是**块缓冲**，日志全憋缓冲区 → 必须 `flush=True`（`_default_log`）。
2. `run_cycle(chat_fn=None)` 显式传 None 覆盖了 `service.breakdown` 的默认 `client.chat` → `'NoneType' object is not callable`；改为 None 时在 run_cycle 内部回落真实上游。
