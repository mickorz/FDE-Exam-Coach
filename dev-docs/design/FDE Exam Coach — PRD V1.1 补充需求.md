这个需求应该加入 Phase 1 的 P0 优先级。

因为你现在距离 11 月 23 日考试只有 24 天，不能只在电脑前刷题。通过 Tailscale，让你在公司、家里或者外出时，都能直接用手机访问 FDE Exam Coach，可以明显提高学习场景的覆盖率。

而且这项能力与第二阶段的微信小程序并不冲突：

- Phase 1： 本地部署 Web 服务，通过 Tailscale 实现手机远程访问。
- Phase 2： 部署公网服务，提供正式微信小程序，不再要求普通用户安装 Tailscale。

## 一、建议的访问架构

电脑 / Mac mini

FDE Exam Coach + 本地数据库

Tailscale 私有网络

安全连接，不需要公网端口映射

手机浏览器

外出随时刷题

其他电脑

访问相同学习记录

这样无论使用电脑还是手机，访问的都是同一个服务端数据库，不需要手动同步进度。

## 二、追加到 PRD 的正式需求

# FDE Exam Coach — PRD V1.1 补充需求

## FR-011 Tailscale 手机远程访问（P0）

**所属阶段：** Phase 1\
**优先级：** P0\
**目标完成时间：** 2026-11-01

### 1. 需求目标

用户在外出时，可以使用 iPhone 或 Android 手机，通过 Tailscale 私有网络访问部署在电脑或 Mac mini 上的 FDE Exam Coach。

手机端和电脑端共用相同的学习进度、错题记录及模拟考试历史。

不需要部署公网服务器，不需要开放路由器端口。

### 2. 功能要求

**FR-011-01 远程访问**

- 支持 Tailscale Serve 反向代理。
- 支持 Tailscale 提供的 HTTPS 访问地址。
- 使用同一 Tailnet 中已授权的手机访问。
- 服务端保持在线时可远程访问。
- 不使用 Tailscale Funnel 公开暴露服务。

**FR-011-02 移动端适配**

必须适配手机竖屏：

- 首页学习仪表盘。
- 章节刷题。
- 单选、多选题。
- 答案提交与解析。
- 错题本。
- AI 问答。
- 今日复习任务。
- 模拟考试。

主要交互按钮应适合触摸操作，避免横向滚动和过小的文字。

**FR-011-03 数据一致性**

- PC 和手机共用服务端数据库。
- 答题记录及时保存。
- 切换设备后可查看最新学习进度。
- 避免重复提交产生重复计分。
- 不允许使用浏览器 localStorage 作为唯一学习记录存储。
- 同一考试在多设备同时编辑时必须有明确的冲突处理规则。

**FR-011-04 服务运行**

- 支持长时间运行。
- 支持服务器启动后恢复 Web 服务。
- 支持查看服务运行状态。
- 应用停止时提供易于理解的错误提示。
- 服务端重启不能导致已保存学习记录丢失。

**FR-011-05 安全要求**

- 应用默认仅监听 localhost。
- 通过 Tailscale Serve 代理访问。
- 不直接暴露数据库。
- 不暴露 AI API Key。
- 不使用公网 Funnel。
- 仅允许经过授权的 Tailnet 设备或用户访问。

### 3. 验收场景

测试一：手机远程刷题

1. 在电脑或 Mac mini 上启动系统。
2. 手机连接 Tailscale。
3. 手机关闭 Wi-Fi，使用移动数据。
4. 通过 Tailscale HTTPS 地址打开网页。
5. 完成 10 道练习题。
6. 返回电脑查看学习记录。

**预期：** 十道题的作答及统计均正确保存。

测试二：错题复习

1. 电脑上答错一道题。
2. 手机进入错题本。
3. 找到刚刚答错的题目。
4. 查看解析并完成复习。

**预期：** 复习结果及时保存并在电脑端可见。

测试三：模拟考试

1. 手机上开始模拟考试。
2. 完成整套模拟考试。
3. 交卷并查看成绩。
4. 在电脑端查看考试历史。

**预期：** 成绩、错题、考试记录一致。

测试四：数据安全

1. 关闭手机 Tailscale 连接。
2. 保持手机使用移动数据。
3. 尝试访问系统的 Tailscale 地址。

**预期：** 无其他授权网络路径时，无法访问服务。

### 4. Phase 2 兼容要求

- Tailscale 只用于第一阶段个人访问。
- 业务 API 不应依赖 Tailscale。
- 前端 API 地址使用可配置方式。
- 第二阶段可切换为公网 HTTPS 服务。
- 不需要重写题库、考试和复习核心逻辑。

## 三、部署建议

考虑你有 Windows 电脑和 Mac mini，我更推荐 Mac mini 作为长期运行的备考服务器，Windows 电脑负责开发，手机负责随时练习。

实际部署时，假设应用运行在 `127.0.0.1:3000`：

```
# 启动 FDE Exam Coach（由项目启动脚本负责）
# 然后配置 Tailscale HTTPS 代理

tailscale serve --bg 3000

# 查看远程访问地址
tailscale serve status
```

Tailscale 官方支持使用 `serve --bg` 持续提供私有 HTTPS 服务，并支持查看服务状态。

[image](https://www.google.com/s2/favicons?domain=https://tailscale.com\&sz=32)

Tailscale Docs+1



手机安装 Tailscale、登录同一 Tailnet 后，就可以通过命令显示的 `.ts.net` 域名访问。注意 Mac mini 必须保持开机、联网，应用进程也必须持续运行。

还有一个我建议加入 P0 的细节：手机页面要支持添加到主屏幕（PWA）。 这样你每天点击桌面图标就能进入备考系统，使用体验更接近小程序，也能提前检验移动端页面设计。

最终，第一阶段的交付目标就变成：PC 能刷题、手机在外能刷题、两端数据统一、AI 能分析错题、系统能帮你持续复习。 这才是 11 月 23 日之前最有价值的版本。
