## 零、定位

FDE-Exam-Coach 需要的不是单纯的刷题系统，而是一个能告诉你"这道题到底在考什么、我为什么不会、应该补哪些知识"的 **AI 备考教练**。

新增两个核心功能：

1. **题目理解障碍分类**：记录为什么不会做这道题。
2. **知识点与考点拆解**：在每道题下面，把要掌握的知识以及考试想考察的能力讲明白。

第一版（P0 迭代）只需完成三件事：**障碍分类、考点拆解、掌握状态记录**。

## 一、题目理解障碍分类

不要只给错题打标签。**答对但靠猜的题目，也必须纳入学习。**

分类分两个维度：

### 维度 A：你是怎么做出答案的？（作答把握程度，单选）

- 确定理解，能够解释答案
- 不太确定，靠排除法作答
- 基本靠猜，不知道怎么选

### 维度 B：这道题哪里不懂？（可多选）

- 知识盲区：涉及的知识点完全没学过
- 术语不懂：题目里的专业名词看不懂
- 考点不明：看得懂题目，但不知道在考什么
- 不会应用：知道概念，但不知道场景下怎么选
- 概念混淆：多个选项感觉都对
- 审题失误：忽略了条件或关键词

示例：一题答对了，但标记了「基本靠猜 + 知识盲区」→ 依然要安排后续学习，不能简单计为已掌握。

## 二、题目下增加"考点拆解"模块（最重要）

现状：`topic` 只表示题目所属主题，`explanation` 解释答案，`distractors` 解释干扰项，缺少一套从**知识到考法**的完整拆解。

目标形态（示意题目，非题库原题）：

> 单选题：某企业希望使用内部知识文档搭建智能问答系统，文档更新频繁，且要求回答能够关联最新资料。应该优先考虑哪种技术方案？
> A 仅依靠模型预训练知识 / B 使用 RAG 检索增强生成 / C 每次更新文档后重新训练大模型 / D 仅依靠 Prompt 编写固定答案

**AI 考点拆解（提交后显示）：**

1. **这道题究竟考什么？**——考察你能否根据"文档频繁更新"和"需要使用最新资料"这两个条件，选择合适的知识增强方案。核心判断：不是问 RAG 的定义，而是问什么业务场景适合 RAG。
2. **必须掌握哪些知识点？**（表格：RAG / Embedding / 向量数据库 / Fine-tuning，各配一句话职责说明）
3. **解题思路与关键判断**——先找业务约束（内部知识、频繁更新、回答需要新资料），再区分"检索外部知识"和"调整模型参数"，本题选 B。
4. **为什么其他选项不合适？**——A 无法保证最新内部文档；C 重训成本高不适合频繁更新；D 固定 Prompt 不能代替动态知识检索。
5. **举一反三，检验是否掌握**——假设不需要频繁更新，而是希望模型稳定采用特定输出格式或任务行为，你会优先考虑哪种方法？为什么？

实际功能中应显示关联的官方产品文档（`sources`）与核实状态。**AI 解析不等于官方标准答案。**

这套设计最大的价值是区分两个容易混淆的概念：

- **知识点**：你需要知道什么。
- **考点**：考试希望你能利用这些知识，做出什么判断。

很多题目不知道选什么，不是缺少名词解释，而是不明白出题者想检验哪一种能力。

## 三、"真正理解了吗"验证

每道题最后增加三个学习状态（用户主动标记）：

| 状态 | 行为 |
| --- | --- |
| 已理解 | 能独立解释考点，并说明选项差异 |
| 部分理解 | 看懂答案，但无法独立推导 |
| 仍然不懂 | 需要进一步解释基础知识 |

标记为「部分理解」或「仍然不懂」的题目，进入**待巩固队列**。

关键约束：**掌握状态不能只靠答题正确率自动判断，要结合用户主动标记。**

## 四、接入方案（P0，不搞复杂架构）

| 现有模块 | 需要修改的内容 |
| --- | --- |
| `app/src/app.js` | 答题后增加障碍分类和考点拆解卡片 |
| `app/src/core.js` | 增加作答把握程度、障碍类型和学习状态 |
| `app/ai/prompts.py` | 新增结构化考点分析 Prompt |
| `app/ai/service.py` | 复用 AI 调用、缓存和限额机制 |
| `app/server.py` | 新增按题目 ID 获取考点解析的 API |
| 学习进度 | 统计知识盲区、蒙对题、考点不明题的数量 |

实施要点：

- 考点解析先**复用题库已有的 `topic`、`sources`、`explanation`、`distractors`**，让 AI 生成结构化知识点与考点内容，再做**缓存**；不必一开始为全部 1000 道题批量生成（按需生成）。
- **正式模拟考试时不显示考点拆解，交卷后才能看**；日常刷题在提交答案后展示，避免影响独立判断。
- **原有 `errorType` 五分类不要直接替换，兼容旧学习记录**；新分类允许一题同时有多个障碍原因。

## 五、最终备考闭环

1. 独立作答——先尝试判断，不提前看解析
2. 记录理解障碍——知识盲区 / 靠猜 / 考点不明 / 概念混淆
3. 学习知识点——术语、原理、场景与相关知识
4. 理解真正考点——考察目标、关键条件、选项判断逻辑
5. 验证与安排复习——举一反三，并根据掌握状态安排复习

## 六、价值

距 11 月 23 日考试还有 20 天。每天做 30 道题，不仅看到正确率，还能知道自己**真正理解了多少道题、还剩哪些知识盲区需要补齐**——比单纯刷满 50 道题更有价值。
