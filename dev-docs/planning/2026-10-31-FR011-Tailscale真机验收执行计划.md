## 1. 背景与目标

FR-011 的全部开发工作已于 2026-10-30 提前完成（多端合并、移动端适配、PWA、启动脚本、launchd、指南），自动化测试全绿（39 node + 15 python，含 `tests/multidevice.test.mjs` 多端并发与 `tests/test_e2e.py` PWA 资源校验）。但 PRD 定义的**四个验收场景从未在真实手机 + 真实 Tailscale 网络上执行**，FR-011 不能视为交付完成。

**本计划目标：** 在真实设备上跑通 PRD 四个验收场景并完成文档收尾，把 FR-011 从"已完成（待验收）"推进到"已验收"。

## 2. 需求分析摘要（验收基准）

FR-011 五个子需求中，验收阶段逐项对应的观测点：

| 子需求 | 验收观测点 |
|---|---|
| FR-011-01 远程访问 | 手机移动数据下经 `https://<机器名>.<tailnet>.ts.net` 打开应用；`tailscale serve status` 正常；全程未用 Funnel |
| FR-011-02 移动端适配 | 手机竖屏完成刷题/考试/错题本/AI 讲解/今日任务，无横向滚动、按钮可触摸、可添加到主屏幕（PWA 全屏进入） |

| FR-011-04 服务运行 | launchd 常驻：重启 Mac 后服务自动恢复；`/api/health` 可查状态；进程停止时手机端有友好错误页 |

## 4. 执行阶段

### E0 环境准备（一次性，约 20 分钟）

1. 选定常驻主机（推荐 Mac mini；若暂用当前开发机，后续迁移时重复 E1 即可）。
2. 主机安装 Tailscale（`brew install tailscale` 或 App Store）并登录。
3. 手机（iPhone/Android）安装 Tailscale App，登录**同一账号（Tailnet）**，开启 VPN 开关。
4. Tailscale 管理后台（login.tailscale.com）→ DNS → 开启 **MagicDNS** 与 **HTTPS 证书**。
5. 确认考试时间压力：本计划建议 2026-11-01 前完成（与 PRD 目标一致），最晚不晚于 11-02。

**E0 完成标准：** 主机与手机均在线于同一 Tailnet（管理后台 Devices 页可见两台设备）。

### E1 常驻部署（主机上，约 10 分钟）

1. 仓库同步到主机（git clone / rsync）。
2. 双击 `deploy/启动备考-mac.command`：确认输出 `http://127.0.0.1:8765` 可访问、`tailscale serve status` 显示 `.ts.net` 地址。
3. 安装开机自启：
   ```bash
   sed "s|__APP_DIR__|<主机上的仓库绝对路径>/app|g" deploy/com.fde-coach.plist > ~/Library/LaunchAgents/com.fde-coach.plist
   launchctl load ~/Library/LaunchAgents/com.fde-coach.plist
   launchctl list | grep fde   # 有输出即常驻生效
   ```
4. 验证重启恢复：重启主机 → 手机直接访问 `.ts.net` 地址仍可用（此步同时覆盖 FR-011-04 观测点）。
5. （可选，AI 讲解需要）配置 `app/local-data/config.json`（从 `config.json.example` 复制）。

**E1 完成标准：** 手机浏览器（Wi-Fi 或移动数据）能打开 `https://<机器名>.<tailnet>.ts.net`，页面正常加载。

### E2 预检（5 分钟，先排雷再验收）

1. **保存链路预检**：手机上随便进章节练习答 1 题 → 侧栏无保存错误。
   - 若报保存失败/403：按 §6 风险 R1 处理（加 `--allowed-host`），处理前不进入正式验收。
2. **PWA 预检**：手机浏览器 → 分享 → 添加到主屏幕 → 从图标进入应全屏无地址栏。
3. 电脑端 `curl 127.0.0.1:8765/api/health` 正常；`git status` 干净（保证学习记录不被测试数据污染——验收会产生真实作答记录，属预期）。

### E3 正式验收：四场景（约 30–40 分钟）

按下表逐项执行并勾选，任一失败按 §6 排查后重跑该场景；全部通过前不进入 E4。

## 6. 风险与预案

| # | 风险 | 现象 | 预案 |
|---|---|---|---|
| R1 | tailscale serve 转发的 Host 头为 `.ts.net` 域名，被 `ALLOWED_HOSTS` 拦截 | 手机端页面能打开但**保存报错**（写操作被拒），电脑端正常 | ✅ **10-31 已修复**：实测严重度更高（整站 403，含读）；server.py 自动放行 `*.ts.net` 非空子域 + Origin 端口归一化，新增 tests/test_tsnethost.py 8 项锁定；详见 dev-docs/experience/tailscale-serve-host-header-403.md |
| R2 | Tailnet 未开 HTTPS 证书 | 手机端证书错误 | 管理后台 DNS 页开启 HTTPS；手机 Tailscale 升级到新版（待用户登录后确认，10-31 批次无法代验） |
| R3 | launchd 路径/权限问题 | 重启后服务未恢复 | `launchctl list \| grep fde` 排查；看 `app/local-data/server.log`；plist 中路径须为绝对路径 |
| R4 | 验收作答污染真实学习记录 | 统计混入测试数据 | 验收产生的作答属真实练习可保留；若要干净环境，先用 `--data-dir` 指向临时目录跑验收，完成后切回（见 app/README.md） |
| R5 | 同场考试双设备并发覆盖 | 答案丢失 | 指南已定义规则（以服务器版本为准）；验收只按场景三第 4 步验证提示，不同时真实作答同一场 |
